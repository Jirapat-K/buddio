# Buddio 🐶

Buddio is a full-stack e-commerce web application
for dog products.

## Project Overview

An online store for dog food, toys, accessories,
and other dog essentials.

## Tech Stack

- Frontend: React, TypeScript, Vite
- Backend: C#, ASP.NET Core
- Database: Oracle Database
- Testing: xUnit, Vitest, Playwright
- AI Development: OpenAI Codex

## Project Status

In Development

## Features (Planned)

- Product Catalog
- Shopping Cart
- User Authentication
- Order Management
- Admin Dashboard
- Sales Reports
